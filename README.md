# Asset-Edge

Asset-Edge is the canonical multi-tenant property management platform for organizations including Stellar Rentals, TB810, Highline, and future tenants.

## Working direction

The platform should be built as a shared foundation with clean organization boundaries.

When adding or changing behavior, ask:

Is this a platform capability, an organization workflow, or an experimental capability?

Prefer small vertical business slices that can be validated by a real customer before being promoted into shared platform capability.
